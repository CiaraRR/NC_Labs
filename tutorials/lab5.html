Choosing a loop

A for loop groups a starting value, continuation condition and update. A while loop checks before its body. A do-while checks afterwards, so its body runs at least once.

for (int step = 0; step < 4; step++) {
  System.out.println("Practise");
}

Stopping safely

Make sure each iteration can move toward stopping. A sentinel is a special exit value, which should be excluded from data calculations. Keep counters and totals separate.

int count = 0;
while (count < 4) {
  System.out.println(count);
  count++;
}

Detailed walkthrough

Choose and trace the loop structure

Use a for loop when a counter naturally describes the repetition. Its header sets the initial value, tests whether to continue, and updates the counter after each body execution.

A while loop tests before its body, so it may run zero times. A do-while loop tests after its body, so it runs at least once. The condition describes when to continue, not when to stop.

Trace a loop using columns for the counter, condition result, body output and update. This exposes off-by-one errors and shows whether the loop can reach a stopping state.

Worked example: a small counted loop

For int k = 1; k <= 4; k++, the body runs with k equal to 1, 2, 3 and 4. After the final update k is 5 and the condition fails.

Changing <= to < removes the final boundary value. Changing the starting value changes the count too. Do not assume the number of iterations equals the upper bound.

For nested loops, trace the outer loop once, then follow all inner iterations for that outer value. The inner loop usually restarts whenever the outer loop moves to its next iteration.

Counters, totals and sentinel input

A counter records how many events occurred; a total accumulates the values involved. Initialise both appropriately and update them only when the relevant event happens.

A sentinel is a special input used to end entry. Read the first value before a pre-tested sentinel loop, test it before processing it, and read the next value inside the body. Exclude the sentinel from sums and counts of ordinary data.

For a largest-value calculation, initialising from the first real data item works with negative data. A complete program should also consider what to report if the user enters the sentinel before supplying any data.

Common mistakes and practice

A condition can stay true forever if the controlling input or counter never changes. Check that the update moves in the correct direction and that the next input is actually read inside the loop.
