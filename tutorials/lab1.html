Program structure

Java statements sit inside methods, and methods sit inside classes. Braces group the statements in a block. A semicolon ends a simple statement.

public class Welcome {
  public static void main(String[] args) {
    System.out.println("Welcome to Java");
  }
}

Output and layout

println ends the output line; print leaves the cursor on the same line. Within a String, \n inserts a new line and \t inserts a tab.

System.out.print("Course: ");
System.out.println("Java");

Detailed walkthrough

Build your first program, step by step

Create a Java class in IntelliJ. Give it a meaningful name and save the source file using that class name.

Place the standard public static void main(String[] args) method inside the class. This is the entry point used in these class examples.

Add one output statement inside main, run the program, and compare the console output with your prediction. Add another statement only after the first works.

Read matching braces from the outside inward: class, method, then any additional blocks. Indentation helps you see the structure, but the braces determine it.

Worked example: predict the layout

Consider System.out.print("Learning "); followed by System.out.println("Java");. The first call leaves the cursor beside its text; the second continues on that line and then ends it. The visible line is Learning Java.

A later System.out.println("Next lesson"); starts on a new line. Spaces inside quotes are part of the output. Spaces used to indent source code are not automatically printed.

Use comments to explain why a statement is present. A comment beginning with // ends at the end of the source line; it is not displayed in the console.

Common mistakes and how to check them

Check System, String and the method names carefully: Java distinguishes uppercase and lowercase letters. A misspelt name is a different identifier.

Use double quotes around text. Close the parentheses and finish a simple output statement with a semicolon. Read the first compiler error before fixing later ones, because one missing symbol can cause several messages.

Keep escape sequences inside a String: a backslash followed by n represents a line break, while a backslash followed by t represents a tab. The exact width of a displayed tab depends on the output environment.
