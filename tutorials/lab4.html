Choosing a path

An if block runs when its Boolean condition is true. An else supplies an alternative. Order an else-if chain carefully because only the first matching branch runs.

if (temperature < 5) {
  System.out.println("Bring a coat");
} else {
  System.out.println("Check the forecast");
}

Comparisons and logic

Use == for equality, != for inequality, && when both conditions must hold, || when either is enough, and ! to reverse a Boolean. Test boundary values as well as typical values.

boolean inRange = value >= 2 && value <= 9;

Try it

Design a decision that accepts a score from 0 to 100. Test -1, 0, 100 and 101. Explain which branch each input reaches.

Detailed walkthrough

Read a decision as a Boolean question

An if condition evaluates to true or false. If true, its block runs; otherwise the program skips it or runs its else block. A chain of else-if branches selects the first matching branch.

Before writing code, express the rule in plain English. Words such as at least, more than, at most and less than describe different boundary behaviour. Translate them carefully into comparisons.

Use braces for multi-statement branches. Indentation makes code readable, but without braces only the next statement belongs to an if.

Worked example: checking a valid range

Suppose valid ages are 16 through 25 inclusive. The valid test is age >= 16 && age <= 25. Both limits must hold at the same time.

The invalid test is age < 16 || age > 25. Either kind of out-of-range input is enough to make it invalid. Test 15, 16, 25 and 26 so that both boundaries are checked.

Negation reverses a Boolean result. For example, !(age < 16) means age is at least 16. Read a negated expression slowly and compare its meaning with the message printed by the program.

Multiple outcomes and switch statements

When grade bands overlap, test the highest threshold first or arrange the comparisons so that earlier branches exclude later cases correctly. Use the constants in the particular example: different lab versions can have different thresholds.

A switch selects a case matching its controlling value. In the traditional case syntax used here, break prevents execution from continuing into later cases. The default branch handles a value without a matching case.

A conditional expression has the form condition ? valueIfTrue : valueIfFalse. It chooses a value; keep longer multi-step decisions in readable if/else blocks.

Debugging and practice

Do not use assignment where you mean numeric comparison. Check whether the message agrees with the condition: a program can compile and still describe the wrong outcome.

Practice: validate a mark, assign one of three categories, and build a small numbered selection menu. For each decision, test a typical value and values immediately below, exactly on, and immediately above a threshold.

Self-check: explain the difference between && and ||, the effect of !, and what happens if two conditions in an else-if chain could both be true.
