Creating and indexing arrays

An array holds several values of one element type. Indices start at zero and end at length minus one. Array length is a field, unlike the String length() method.

int[] scores = {12, 18, 24};
System.out.println(scores[0]);

Traversing and searching

Visit only valid indices. Keep a sum for accumulated values, a count for occurrences, and a found flag for search status. Parallel arrays share an index for one record.

for (int i = 0; i < scores.length; i++) {
  System.out.println(scores[i]);
}

Tables and objects

A two-dimensional array uses row and column indices. Reset totals for each new row or column average. An object array stores references; null means no object reference is present.

Try it

Store five numbers, display them in reverse, and find their minimum and maximum. Explain how a search reports that a value is absent.

Detailed walkthrough

Think in elements, indices and bounds

An array holds a fixed number of elements of one declared type. The length is the number of elements; the final valid index is one less than that length. Use meaningful names for both the collection and its loop index.

An int array created with new contains zero-initialised elements. An array of object references initially contains null references until objects are assigned to those positions.

Accessing an index outside the valid range raises an exception. Before tracing any array expression, check both its index value and the array’s length.

Worked example: traversing a small array

For int[] values = {6, 11, 15};, valid indices are 0, 1 and 2. A loop beginning at zero and continuing while i < values.length visits every element once.

A running total starts at zero and adds values[i]. The total is 32. For a decimal average, convert an operand before division; converting an already truncated result cannot restore the missing fraction.

A reverse-output loop starts at values.length - 1 and decreases to zero. This changes the visiting order; it does not change the original element order unless assignments are also made.

Searching, tables and related records

A linear search checks elements in turn. To find the first match, continue only while no match has been found and the index remains valid. To count every occurrence, examine the whole array instead of stopping at the first match.

Parallel arrays share an index for one record, such as a bus ID, make and capacity. A two-dimensional array uses two indices, commonly row and column. Reset a row or column total before starting the next average.

An object array can group related fields into objects. Check for null when a search might return no matching object. A toString method supplies readable text when an object is printed.

Common mistakes and practice

Do not use <= array.length as the ordinary traversal limit. Do not initialise a maximum to zero if all data might be negative. Distinguish the index of a match from the matching value itself.
