Types and assignment

Choose int for whole numbers, double for decimals, boolean for true/false, char for one character, and String for text. Assignment replaces the current value.

int books = 7;
double cost = 2.75;
books = books + 2;

Calculations

Use parentheses to group a calculation. Integer division discards the fractional part. Convert an operand to double before division when you need a decimal result.

int total = 17;
double average = (double) total / 4;

Detailed walkthrough

Understand declaration, initialisation and assignment

A declaration introduces a variable name and its type. Initialisation supplies its first value. A later assignment replaces the stored value. The equals sign in an assignment does not mean an algebraic equality test.

Choose a type based on the data: a count normally needs an integer; a measured value may need a decimal type; a label needs text. A numeric-looking identifier such as a room code can still be a String.

A local variable must be assigned before its value is read. Choose descriptive camelCase names so you can tell what the stored value represents.

Worked example: trace changing values

Start with int tickets = 6; and int extra = 3;. After tickets = tickets + extra;, tickets contains 9 and extra still contains 3. The expression on the right is evaluated before the assignment replaces the value on the left.

If you then set extra = tickets;, extra receives a copy of the current integer value. Updating tickets later does not automatically update extra. Trace each assignment on a separate row of a table.

For a swap, first preserve one value in a temporary variable. Without the saved copy, assigning the second value over the first can destroy information you still need.

Arithmetic, casting and display

Multiplication and division are evaluated before addition and subtraction unless parentheses change the grouping. Use brackets to make a formula clear even when you already know the precedence.

When both operands are integers, division produces an integer result. For example, 11 / 4 is 2, whereas 11.0 / 4 is 2.75. Casting the completed integer result afterwards cannot recover a discarded fraction.

Formatting changes how a result is displayed. A DecimalFormat pattern does not change the original numeric variable. Be careful to distinguish a rounded display from the stored value.

Common mistakes and practice

Do not confuse a quoted number with a numeric value. Check whether + is adding numbers or joining text. In an output expression, parentheses can ensure a calculation happens before concatenation.

Practice: calculate the cost of several tickets, swap two integer values, and trace a pre-increment and a post-increment separately. Use small values and record every change.

Self-check: explain why an integer division result may surprise you, why a temporary variable is useful, and how the scope of a local variable limits where its name can be used.
