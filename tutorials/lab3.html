Keyboard input

Create a Scanner for System.in. Prompt before reading. nextInt reads an integer, nextDouble reads a decimal, next reads a token, and nextLine reads the rest of a line.

Scanner input = new Scanner(System.in);
System.out.print("How many books? ");
int books = input.nextInt();

Text after numeric input

A numeric read can leave a line ending behind. If a full-line text read follows, consume the leftover line ending first. A character can be extracted from a nonempty String using charAt.

int age = input.nextInt();
input.nextLine();
String fullName = input.nextLine();

Detailed walkthrough

Plan an input–process–output program

Write down the required inputs, their types, the calculation, and the labels needed in the output before writing Java. A prompt should tell the user what to enter and which unit to use.

Create a Scanner connected to System.in and use the appropriate reading method for each value. The variable type and input method should agree with the kind of data accepted.

A numeric Scanner method expects valid numeric text. These introductory examples do not automatically handle every invalid input: entering words where an integer is expected can cause an input exception.

Worked example: a shopping calculation

Suppose the program reads quantity 3 and unit price 4.25. Store quantity as int and unit price as double. Multiplying them gives a total of 12.75.

If the customer tenders 20.00, subtract the full total from the amount tendered. Check the calculation manually before trusting the program. Label the total and change separately.

Test with a quantity of one, a price containing cents, and an exact payment. Decide what the program should do if the payment is too small; a negative result is data you need to interpret, not a valid positive change amount.

Reading text and characters reliably

next() reads one token separated by whitespace. nextLine() reads the rest of the current line and can include spaces. Pick the method based on whether a full name or only one word is required.

After a numeric read, the remaining line ending can make a following nextLine() return immediately. Consume the remainder deliberately before asking for a full line of text.

charAt(0) extracts the first character of a nonempty String. An empty String has no character at position zero, so a more robust program should check for empty input before extracting it.

Constants, conversions and practice

A final variable records a value that cannot be reassigned after initialisation. Use named constants for fixed conversion factors and rates, and keep units clear in names or prompts.

For a conversion, first decide whether the input must be multiplied or divided by the factor. Check a familiar value manually, then try a zero value and a decimal value.

Practice: read a full name and two prices, display their sum with two decimal places, then build a separate unit-conversion program. Explain every input method you chose.
